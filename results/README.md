# Selected results

The table `topological_consistency.csv` contains the numerical summary used to compare the `25 × 25` and `36 × 36` deterministic subsamples.

At both resolutions, the dominant persistent-homology signature is:

- one connected component,
- two dominant classes in H1,
- one dominant class in H2,
- Betti numbers `(β0, β1, β2) = (1, 2, 1)`.

Distances, filtration parameters, coverage radii, and persistence values are expressed in ångströms. Separation ratios, Betti numbers, and the Euler characteristic are dimensionless.

Short-lived classes are reported as secondary classes; they are not automatically identified as noise.
